# 🎯 Java Number Guessing Game

A console-based **Number Guessing Game** developed in Java. The application generates a random number between **1 and 100**, prompting the user to guess the correct number while providing real-time feedback after each attempt.

---

## 🚀 Features

- **Random Number Generation**: Dynamically selects a secret integer between `1` and `100` using `java.util.Random`.
- **Interactive Feedback**: Hints whether your guess is **Too High** or **Too Low**.
- **Attempt Tracking**: Counts and displays the total number of attempts taken to guess correctly.
- **Clean Console Output**: Clear and user-friendly interface.

---

## 🛠️ Tech Stack & Concepts Used

- **Language**: Java
- **Core Concepts**:
  - Control Flow (`while` loops, `if-else` decision structures)
  - Randomization (`java.util.Random`)
  - User Input Processing (`java.util.Scanner`)

---

## 🖥️ How to Run

### Prerequisites
Make sure you have Java (JDK 8 or higher) installed on your system.

### Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/sivasekhar-939/java-intership03.git
   cd java-intership03
   ```

2. **Compile the Java File**:
   ```bash
   javac NumberGuessingGame.java
   ```

3. **Run the Game**:
   ```bash
   java NumberGuessingGame
   ```
